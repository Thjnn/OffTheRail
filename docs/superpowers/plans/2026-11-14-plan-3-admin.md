# Off the Rail v2: Kế hoạch 3, admin cho chủ shop và nhân viên

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Chủ shop vận hành được cửa hàng trong `/admin`: đăng nhập nhân sự, phân quyền owner/staff, tổng quan có biểu đồ, xử lý đơn web, nhập tay đơn Shopee, sản phẩm + biến thể + ảnh + kho, khách hàng, nhân viên, nội dung web, cài đặt, xuất Excel, nhật ký, báo đơn mới.

**Architecture:** Toàn bộ route admin nằm trong `routes/admin.php` dưới middleware `web` + `auth:admin`. Quyền chỉ có hai mức: Gate `owner` cho route, trait `OwnerOnly` cho Livewire component (chạy lại ở mọi request Livewire). Mọi thay đổi trạng thái đơn đi qua `OrderService`, mọi thay đổi kho qua `Inventory`, mọi thao tác nhạy cảm ghi `ActivityLog::record()`. Livewire cho bảng có lọc và form phức tạp; thao tác đơn lẻ là controller + Blade.

**Tech Stack:** như Kế hoạch 2. Thêm: `openspout/openspout` (bản còn hỗ trợ PHP 8.3), `apexcharts` (npm).

**Spec:** `docs/superpowers/specs/2026-11-13-offtherail-laravel-design.md` (mục 5.2, 6, 7, 8, 9 "Admin + POS", 10, 11, 12)
